# Capturing another scene

Keep the scene static and capture slow, overlapping, sharp views. Cover the top, sides and rear that the viewer will display. A single-height orbit can miss the underside and occluded background. A panoramic camera is unnecessary.

For editing, separately capture the empty support surface with surrounding objects in place. Select an object with a distinct outline for the first trial. Avoid rapid zoom, large exposure changes, reflective surfaces and moving objects. Inspect camera registration, reprojection error and a held-out render before feature training.

Use a fresh dataset directory for each capture. The photo ingestion path applies image orientation and writes clean pixel images. Source names are replaced by frame numbers. Keep raw camera media separate from derived images when moving a project between machines.
