Video reconstruction, semantic search and object manipulation

1. Import a video

Frames are sampled before camera estimation and Gaussian training. Training may take a while. Follow or cancel the job below.

2. Select a scene and a query



Inspect candidates for missing geometry and background fragments. Adjust the threshold or radius before running the query again. The largest cluster can be incorrect. Negatives compete with the query; the defaults name desk02 objects, so replace them with categories visible in a new scene.

3. Inspect and manipulate
Enable the heatmap to inspect scores. Disable it to move a candidate using the XYZ axes or rotation rings. Switching candidates resets the transform. You can isolate, reset or export the current pose.
